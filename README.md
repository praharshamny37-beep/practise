Project Scope

The project files included in this repository document the development of the hull geometry for the proposed next-generation corvette. The work covers:

Selection of a suitable parent hull from the NPL Series.

Generation of scaled hull offsets.

Preparation and verification of final offset tables.

Development of the hull lines plan.

Three-dimensional hull modelling.

Hydrostatic calculations and verification.

Supporting report, LaTeX source files, drawings, spreadsheets, and model files.

NPL Hull Form Generation

The hull offsets were developed using the selected NPL Series parent hull. The parent-hull dimensions and offsets were scaled according to the required principal dimensions and draft ratios. The resulting station-wise and waterline-wise offsets were used as the basis for the subsequent hull-form development.

Lines Plan Development

The final offsets were used to prepare the hull lines plan in AutoCAD. The drawings include the body plan, half-breadth plan, sheer plan, Bonjean curves, and hydrostatic-related drawings.

3D Hull Modelling

The hull geometry was developed as a three-dimensional model using Rhinoceros (Rhino). The developed hull model was also transferred to Maxsurf for hydrostatic analysis and verification of the hull characteristics.

Software Used

The project work was carried out using the following software:

AutoCAD – preparation of the hull lines plan and technical drawings.

Rhinoceros (Rhino) – three-dimensional hull modelling and surface development.

Maxsurf – hull analysis and hydrostatic calculations.

Microsoft Excel – offset calculations, data processing, and verification.

LaTeX – preparation of the project documentation.
